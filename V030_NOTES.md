# v0.30 Color Lab
Base: tests.zip (latest user revision). Effects > select image > Color Lab. Three independently enabled operations: three-stop gradient with adjustable midpoint, nearest-color palette (2–16 editable colors, dominant RGB histogram extraction from original), Bayer 4x4 or deterministic noise dithering. Internal order gradient → dithering → palette; Color Lab itself is reorderable in the existing chain. Uses existing canvas/export renderer and undo sessions. No new dependencies. Palette extraction ignores near-transparent pixels and caps full image readback at 16 megapixels. Dithering grid uses normalized layer coordinates (1024 reference units per axis), not original pixel coordinates. No Floyd–Steinberg/Atkinson yet. Two new pure tests pass; syntax transpilation passed; full typecheck and lint blocked by missing dependencies, native shader execution untested. Existing package version retained.
